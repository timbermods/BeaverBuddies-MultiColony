The changelog of BeaverBuddies MultiColony is STABILITY-CHANGELOG.md at the repository root, one entry per
version, newest first, back to the Stability Fork's first change over the original BeaverBuddies v1.1 branch.

The short in-game version (the text the changelog dialog would show; the dialog is off in this fork, see
Help/ChangeLogService.cs) is BeaverBuddies/changelog.txt, embedded as the ChangeLog resource.

This file used to hold the original project's draft notes for its 1.5.0 release (Steam networking, in-game
settings); those are in the original's history at https://github.com/thomaswp/BeaverBuddies.
