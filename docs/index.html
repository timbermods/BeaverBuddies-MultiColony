Timber Together

Build apart. Thrive together.

Co-op Timberborn where each player runs their own colony on one shared map, and the colonies trade at Trading Posts.

Ordinary BeaverBuddies co-op puts everyone in one colony. Here you're neighbors: your own districts, beavers and science, next door to a friend's.

How it works

One map, a colony each, and one rule between the colonies.

  1. One map

    Host any map: one of the game's own or a multi-start map. The river, the weather and the droughts are shared by everyone.

  2. A colony each

    Each player runs their own districts, beavers, stock, working hours and science. Nobody else can change your buildings, and your beavers work only for you.

  3. Barter at Trading Posts

    Your roads never join theirs, except through a Trading Post placed between them. Offer goods, science or beavers; each round crosses once both sides are in.

Choose your start

The host chooses it where the game is made: a new game on the New Game page, a save you already share on its Co-op Game page. Both use the same checkbox, Separate colonies.

Your shared colony stays; friends start fresh

TickSeparate colonies, on the save's Co-op Game pageShown for a shared save: a single-player game, a shared co-op save or a Stability Fork save. Your friends' pages say so.
Your pickSeparate science and unlocks, under itTicked, each colony earns its own science from then on, and what you earned so far stays yours. Unticked, the colonies share it.
  1. Main menu → Host co-op game (under Load game), pick the save → Host co-op game.
  2. Tick Separate colonies on its Co-op Game page. Friends join and press Ready; you press Start Game.
  3. At Start the game becomes separate colonies for good, and it can't be undone. Keep a copy of the save first. Each friend then places their district center anywhere its roads won't join yours.

What happens: everything built so far stays whole as your colony, with its buildings, beavers, fields, science and unlocks. Each friend starts from scratch: a new district center, already built, with starting beavers, food and water.

Not sure your save is shared? In the Host co-op game box, a gold line under the save's picture says Separate colonies or One shared colony. Rather build one colony together, as in ordinary BeaverBuddies? Leave Separate colonies unticked. A friend who later wants their own colony can split off once, from the game menu (Esc → Found your own colony); the shared colony stays the host's, and science stays shared. Timber Together's co-op fixes apply either way.

Install

Host and friends alike. Five steps, then one check together before you join.

Both players do this

Every player, the host included. Most co-op trouble comes from skipping one of these.

  • The same download. The exact same Timber Together zip on every computer. A different build can't join.
  • One BeaverBuddies only. Delete every other BeaverBuddies folder in Mods (the Stability Fork, the Workshop version, any other Timber Together copy) and unsubscribe from the Workshop BeaverBuddies.
  • Harmony and Mod Settings enabled. Timber Together needs both.
  • The same game. Timberborn 1.1.2.4. The Steam version on Windows is what has been tested.

  1. Download the zip

    Open the newest release on GitHub and download TimberTogether-1.4.0-rc4.zip under Assets (not "Source code"). Got a zip from your host? Use that exact file instead.

  2. Close Timberborn

    The game must not be running while you change its mods.

  3. Remove every other BeaverBuddies

    In Documents\Timberborn\Mods, delete BeaverBuddies-Stability-Fork or BeaverBuddies-StabilityPreview (the Stability Fork) and any other copy of TimberTogether. Unsubscribe from the Workshop BeaverBuddies in Steam. Your saves aren't kept in the Mods folder, so this doesn't touch them.

  4. Copy in the new folder

    Extract the zip and copy the TimberTogether folder into:

    Documents\Timberborn\Mods

    You should end up with Mods\TimberTogether\version-1.1\manifest.json.

  5. Enable the mods

    Start Timberborn, open the mod manager and enable Harmony, Mod Settings and Timber Together. Restart if the game asks you to.

Read them out to each other. All three must match.

Sending this to a friend? Full install guide

Playing together

Invite first and start together. Then each of you runs your own colony, whoever is online.

The Co-op Game page

Every game is hosted through it, new or saved: everyone joins first, then you all load it together, paused.

Host

  1. New Game → … → Host co-op game beside Start, and name your settlement. For a save: main menu → Host co-op game. Playing alone: Esc → Host co-op game.
  2. Invite Friends over Steam, or give your IP (port 25565).
  3. Press Start Game when everyone shows Ready.

Friends

  1. Main menu → Join co-op game lists your Steam friends' games: pick your host's and press Join. Or accept the invite, or type the host's IP.
  2. Press Ready.
  3. In the game, place your district center when it's offered.

Nobody can join after Start Game. To let someone in later, or after a dropped connection, the host uses Save and Rehost: friends choose Rejoin and land on the page as soon as it opens. The page has been opened and joined in a playtest; starting a whole game from it, and hosting a save or a game you're playing, haven't been played yet.

Folktails and Iron Teeth together Not played yet

The host ticks Mixed factions under Separate colonies on the New Game page, and each player picks a faction on the Co-op Game page with the game's own switcher. Your colony gets your faction's toolbar, beavers, bots, buildings and storage. Between factions, Trading Posts carry the goods both use, and science, never beavers.

Needs every faction unlocked on the host's computer; otherwise the box is greyed and its tooltip says why. With a mod that adds a faction, new games stay one faction.

Away for a while? Your colony waits Not played yet

A colony is kept for its player while they're away. To keep it running, ask a friend to look after it: Ctrl+T, then Let … look after it on your colony. They press Run this colony to play it as yours and Back to your colony when done; Take it back whenever you like.

For a group where someone may not come back, the host can set Hand over a colony after its player is away (days). It's 0, never, by default, and an absence never hands a colony to the other faction.

Your colony, your rules

  • Yours alone

    Your districts, beavers, stock, working hours and marks. Nobody else can pause, rename, demolish or re-staff your buildings, and your beavers build, cut, plant and gather only for you.

  • Build anywhere

    No land and no borders: build right up to a neighbor. The one rule is that your roads never join theirs. Ctrl+L shows every colony's roads in its color.

  • Your own science

    With Separate science and unlocks ticked (it is by default), each colony earns its own science and unlocks its own buildings and bot types.

  • Remembered by the save

    The save knows you by your Steam ID, so you get the same colony whoever hosts. A colony with no beavers or bots left for a whole day goes to the nearest living colony, and its player can found again with Ctrl+K.

  • Shared by everyone

    Speed, pause, pings, chat, saving, and the map itself: water, droughts, badwater and weather. A dam upstream still changes what flows downstream.

  • Up to four colonies

    A fifth player or more shares the host's colony.

Things to try

  1. Press Make offer. Player 2 accepts after a moment; your workers bring the logs to your half and theirs bring the gears to theirs. The round crosses only when both bars are full, and the ledger gets a line.
  2. Untick answers by itself, make an offer, then switch to Player 2: you see the offer from their side, with Accept and Decline. Every exchange in the game is agreed this way, one player per side. (The panel names a colony by the player who runs it, as the game does.)
  3. Set Workers on your half to 0 during a round: your side stops arriving and the status line says why. Nothing crosses until it is in.
  4. Press Cancel exchange mid-round. The other player must agree; until then nothing moves. Once it ends, what waited on each half goes back home.
  5. Type 150 in an amount box: the line turns red and Make offer grays out. Set Rounds higher instead, or tick Repeat until cancelled.

Also included

Everything from the BeaverBuddies Stability Fork that Timber Together is built on, including its fixes for the crashes and desyncs that made co-op painful.

  • Steam invites

    Invite friends from Steam's overlay, with no port forwarding. Direct IP and Hamachi work too.

  • Connection panel and chat

    Who's connected and which colony they run, ping, sync status and tick rate, with chat and a speed boost.

  • Pings

    Bind Ping Location and mark a spot on everyone's map, in your own color.

  • Player cursors

    See your friends' cursors, selections and what they're editing, anywhere on the map.

The host decides

Every action goes through the host, which checks it against the colony rules and plays it for everyone, or refuses it with a reason.

Ownership is saved

Who owns each district, building and mark is in the save, the same on every computer. Beavers take their work from these only.

Out of step? It stops at once

In a separate-colonies game every computer checks its colonies against the host's as the game runs; a difference stops the game straight away, and the log names it. The full rules

Something broke? Send this

Open an issue on GitHub with these files from every player, not just the one who saw the problem.

Open an issue
  1. Player.log, from %USERPROFILE%\AppData\LocalLow\Mechanistry\Timberborn. Close the game first so it's complete.
  2. The newest report in the TimberTogether-Reports folder next to it. When a separate-colonies game desyncs, every computer writes one by itself; Ctrl+Shift+J writes one any time.
  3. What you were doing, plus screenshots of anything on screen.

Good to know before you play

  • Everyone runs the exact same build of the mod and the same game version; the join is refused otherwise. Other mods should match too (you get a warning).
  • Join before the host starts. The Co-op Game page closes at Start Game; after that, the host uses Save and Rehost to let someone in.
  • Only one BeaverBuddies at a time. If another is enabled, the main menu names it and this one stays out of the way.
  • The map is shared. The game ends only when every beaver on the map is gone.
  • A mixed-factions save needs this mod. Opened in the plain game or the Stability Fork, it loads one faction and drops the other's buildings and beavers.
  • Text is English only for what this mod adds.

Logs include file paths with your Windows user name; look through them before you post if that matters to you. More in the FAQ.

Troubleshooting

The problems people hit most. Everything else is on the troubleshooting page.

Can't join: "Multiplayer build mismatch"

Why

Someone's game version, mod version or mod files differ from the host's. Two different builds can't stay in step, so the join is refused before the save is sent, even when the version numbers match.

Try this

Update together: everyone installs the same zip, replaces the TimberTogether folder and fully restarts the game. Then compare the three readings again.

A friend lost the connection, or wants to join late

The host chooses Save and Rehost in the game menu, and the friend chooses Rejoin (or waits in Join co-op game). Everyone meets on the Co-op Game page, and Start Game carries on. It doesn't matter who presses first.

The mod doesn't start, or the main menu names another BeaverBuddies

Why

A leftover BeaverBuddies is still installed. Timber Together, the Stability Fork and the Workshop BeaverBuddies change the same parts of the game, so only one can run.

Try this

Delete every other BeaverBuddies folder from Documents\Timberborn\Mods, unsubscribe from the Workshop version, and restart the game.

"That would join another colony's roads"

A path of yours would touch their road, or a building's door would open onto or beside it. Keep your roads a cell apart from theirs; to link the two colonies, put a Trading Post between them. Ctrl+L shows whose roads are whose.

A Trading Post says "Not trading yet"

Each half needs a different colony's road at its door: yours at one end, theirs at the other. It starts trading as soon as both roads reach it.

Every game is hosted through a Co-op Game page

Host co-op game on the main menu opens the game's own save box for any save, with a gold line saying whether it's separate colonies or one shared colony. Playing alone, Esc → Host co-op game saves your game and opens its page. Friends join and press Ready, and Start Game loads it for everyone at once. Separate or shared, chosen where you make the game

A new game's Separate colonies checkbox sits on the New Game page, beside the game's own Tutorial checkbox, with Separate science and unlocks and Mixed factions under it. A shared save can be made separate colonies on its Co-op Game page, and a friend in a shared game can split off once with Found your own colony in the game menu.

None of this has been played yet. It's built from the game's own boxes and buttons and covered by automated checks; Script H walks through it with two players.
