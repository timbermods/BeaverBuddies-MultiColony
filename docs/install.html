Install guide

From download to your first co-op game. Every player follows the install steps and the check with the host; only the host loads a save.

Before you start

  • Timberborn on every player's computer. Timber Together is built and tested against version 1.1.2.4 on Windows with the Steam version of the game, and everyone must run the same game version.
  • The Harmony and Mod Settings mods, which Timber Together needs. Get Harmony from the Steam Workshop and Mod Settings from the Steam Workshop or mod.io.
  • For Steam invites: both players online in Steam and both owning Timberborn on Steam.
Same zip for everyone

The mod checks the game version and its own files when someone joins, and refuses any difference. It's the most common cause of trouble, so install the exact same zip on every computer.

Install the mod

  1. Download the zip

    Open the newest release and download TimberTogether-1.4.0-rc4.zip under Assets, not "Source code". Got a zip from your host? Use that exact file instead. The release also lists the zip's SHA-256 if you want to check the download (see below).

  2. Close Timberborn

    Make sure the game isn't running while you change its mods.

  3. Keep only one BeaverBuddies

    Unsubscribe from the Workshop BeaverBuddies, and delete every other BeaverBuddies folder in Documents\Timberborn\Mods: the Stability Fork (BeaverBuddies-Stability-Fork or BeaverBuddies-StabilityPreview) and any other copy of TimberTogether. They change the same parts of the game and can't run together; if one is still enabled, the main menu names it. Your saves aren't kept in the Mods folder, so this doesn't touch them.

  4. Extract and copy

    Extract the zip and copy the TimberTogether folder into your Timberborn Mods folder:

    Documents\Timberborn\Mods

    You should end up with Mods\TimberTogether\version-1.1\manifest.json.

  5. Start Timberborn and enable the mods

    Open the mod manager from the main menu and enable Harmony, Mod Settings and Timber Together. Restart the game if it asks you to.

To check the download, open PowerShell in the folder you saved it to and compare the result with the SHA-256 on the release page:

Get-FileHash .\TimberTogether-1.4.0-rc4.zip -Algorithm SHA256

Compare with your host

Before anyone hosts, read these three out to each other. All three must match on every computer.

WhatShould readWhere to look
The mod1.4.0-rc4The mod list shows Timber Together with its version.
The game1.1.2.4The same Timberborn version for everyone.
The downloadThe same zipThe same file, not only the same number: compare the SHA-256 if in doubt. A copy someone built themselves won't join.

If anything differs, joining is refused with Multiplayer build mismatch, which names what differs. Update together: everyone replaces the folder with the same new zip and restarts the game.

Check it loaded

  • The mod list shows Timber Together with version 1.4.0-rc4.
  • The main menu has a Join co-op game button.
  • Your game log, %USERPROFILE%\AppData\LocalLow\Mechanistry\Timberborn\Player.log, contains the line Timber Together v1.4.0-rc4 is loaded!

If it isn't there, see The mod doesn't load.

Host a game

Every game is hosted through a Co-op Game page: friends join it and press Ready, and Start Game loads the game for everyone at once. You choose separate colonies or one shared colony where the game is made, with the Separate colonies checkbox:

  • A new game, a colony each: leave Separate colonies ticked on the New Game difficulty page. It's ticked by default, and the page remembers your choice.
  • Splitting a save you already share: tick Separate colonies on the save's Co-op Game page. Everything built so far stays your colony; each friend founds their own.

Choose your start shows the two side by side.

A new game

  1. New Game → faction → map → difficulty, as usual. Tick or untick Separate colonies (and the two boxes under it), then choose Host co-op game beside Start and name your settlement.
  2. On the Co-op Game page, bring your friends in with one of the three ways below. They appear in the list and press Ready; you can remove anyone.
  3. Press Start Game (you're asked first if someone isn't ready). Everyone loads the new world together, paused; unpause when the connection panel shows nobody (loading). Nobody new can join after Start.

Starting a game from the Co-op Game page hasn't been played yet: please report how it goes.

A save

From the main menu choose Host co-op game (under Load game). It opens the game's own save box: pick a settlement and a save. A gold line under its picture says what it is: Separate colonies (with how many players it remembers) or One shared colony. Choose Host co-op game; its Co-op Game page opens. Invite, let everyone ready up, and press Start Game. Each player gets the colony the save remembers for them. Load game only loads.

For a shared save the page also shows Separate colonies, unticked, with Separate science and unlocks under it. Tick it and the game becomes separate colonies at Start, for good: everything built so far is your colony, and each friend founds their own. Keep a copy of the save first.

From inside a game

Playing alone, open the game menu (Esc) and choose Host co-op game: your game is saved as a new save and its Co-op Game page opens. Hosting a co-op game, the same button reads Save and Rehost: everyone leaves the game, it's saved, and its page opens. Your friends choose Rejoin (or Reconnect after a desync) and land on the page as soon as it opens; when everyone is ready, Start Game carries on. Nobody can join after Start Game.

Hosting a save or a game you're playing, and rejoining a rehost, haven't been played yet.

If a warning says your mods and a friend's mods differ, fix that before you start: see Troubleshooting.

Option 1: Steam invite (easiest)

Make sure Enable Steam Networking is on in Mod Settings (it is by default), choose Invite Friends, and pick your friend in Steam's overlay. No port forwarding or extra software is needed. If nothing happens in the first moment after hosting starts, click the button again: the Steam lobby is still being created.

Option 2: Direct IP

Give your friend your IP address. The default port is 25565, and your router must forward it to your computer. Direct IP is offered at the same time as Steam invites: whenever you host, anyone who can reach that port can join until the game starts, and the host can't check who they are. Forward the port only while you play by IP with people you trust (see the FAQ).

Option 3: Hamachi or another virtual network

A virtual LAN such as Hamachi avoids port forwarding, and has been tested and works. Give your friend the address the virtual network assigns you, then they join by direct IP.

Join a game

From the main menu

Choose Join co-op game: it lists your Steam friends' co-op games. Pick your host's and press Join. You see the host's Co-op Game page; press Ready. A game that has already started may drop off the list. Under the list you can also type the host's IP address or domain name.

With a Steam invite

Accept the invite from the Steam notification or overlay, from the main menu: every game is hosted through a Co-op Game page. If Timberborn is closed, Steam launches it and joins for you. If the host has Allow Friends to Join Directly via Steam on (it is by default), you can also use Join Game from the host's entry in your Steam friends list.

Guests receive a copy of the host's save. It's kept under Online Games.

Found your colony

As soon as you're in, even while the game is still paused, a message offers you a district center to place (or press Ctrl+K later). Put it anywhere its roads won't join another colony's (their roads show in their colors): it appears already built, free, with starting beavers, food and water. On a multi-start map you get the next start instead. The save remembers your colony by your Steam ID (without Steam, by an id kept on your computer), whoever hosts.

While you play

  • The connection panel shows who is connected and which colony they run, their ping, whether you're in sync and the tick rate. Click its title to collapse it.
  • Each colony's roads show as bright squares in its color while you place a building, or with Ctrl+L. Yours must not join another colony's: keep your paths a cell away from its roads and district center. The one place two colonies' roads meet is a Trading Post, placed between one road end of each. Ctrl+T lists your Trading Posts and every colony. The rules are in TWO-COLONIES.md.
  • Stepping away? In the Ctrl+T window, press Let … look after it on your colony so a friend can run it until you're back.
  • Your friends' cursors and selections appear on your screen. Change how each looks in Options (Esc), Player cursors; the same dialog sets the color you see your own name in, in the chat.
  • To ping a location on the map for everyone, bind a key for Ping Location in the game's keybinding settings.
  • Set your own Ping Display Name and Ping Color in Mod Settings so your friends can tell you apart.

If a desync happens

A desync means the players' games have drifted apart. The game tells you, and the host should:

  1. Choose Save and Rehost.
  2. Guests choose Reconnect (wait for Rehost), in any order. Each goes to the main menu and lands on the host's Co-op Game page as soon as it opens: a direct IP guest redials the address it used; a Steam guest joins the host's new lobby when Steam shows it (the host needs Allow Friends to Join Directly via Steam on), or else accepts a fresh invite.
  3. Everyone presses Ready, and the host presses Start Game.

If the game says multiplayer has stopped because an action couldn't be completed, return to the main menu and reload a known-good save. Don't overwrite your good save with that session. Then send every player's Player.log and newest report: how.

Settings and keys

On the New Game page (the host's choice)

A new game's colonies are chosen on the New Game difficulty page, under the game's own Tutorial checkbox. The page remembers your last choice, and a game keeps what it was made with, for good. A shared save's Co-op Game page shows the first two as well.

CheckboxDefaultWhat it does
Separate coloniesTickedTicked: each player builds their own colony. Unticked: everyone plays one shared colony, as in ordinary BeaverBuddies; a player other than the host can split off later, once, with Found your own colony in the game menu. Not played yet.
Separate science and unlocks (under it)TickedEach colony earns and spends its own science and unlocks its own buildings. Unticked: the colonies share one pool.
Mixed factions (under it)UntickedEach player picks Folktails or Iron Teeth for their colony on the Co-op Game page. Greyed, with the reason in its tooltip, unless every faction is unlocked on the host's computer. Not played yet.

In Mod Settings (the host's)

Open Mod Settings from the game's mod menu and choose Timber Together. The connecting settings and your own preferences, below, are there as well.

At 0 an away player's colony is kept for them; ask a friend to look after it instead. In a mixed game it only ever goes to a colony of its own faction. It can be changed during a game.

Update or remove

  • Update: download the new zip, close the game, and replace the TimberTogether folder. Everyone updates together, because different builds won't join each other.
  • Remove: disable the mod in the mod manager, or delete the TimberTogether folder from Mods.
